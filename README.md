# 🍪 Cookies Farm Extension (Pro Edition)

Chrome extension untuk "warm up" profil browser anti-detect melalui aktivitas browsing otomatis yang organik.

## 🚀 Fitur Utama

### 🛡️ Anti-Detect Level Pro
- **Referrer Spoofing**: Trafik terlihat datang dari Google, Facebook, Twitter, dll
- **Mouse Trail Simulation**: Gerakan mouse realistis dengan easing curves
- **Tab Focus Simulation**: Simulasi multitasking (buka-tutup tab random)
- **Random Stay Time**: Variasi waktu tinggal ±5 detik per website
- **Smart Clicks**: Menghindari tombol Login/Signup

### 🤖 RPA Compatible
- **Anti-Close-Other-Tabs**: Tidak menutup tab RPA dashboard
- **Anti-Suicide Browser**: Mencegah browser close sendiri
- **Instant Start**: Mulai tanpa delay, tanpa tutup tab aktif

### ⚙️ Kontrol Lengkap
- **Pause/Resume**: Jeda farming kapan saja tanpa reset
- **Progress Bar**: Visualisasi progress real-time
- **Dark Mode**: Tema gelap untuk mata
- **Real-Time Stats**: Pantau jumlah website visited langsung

## 📋 Website Target
- YouTube, Facebook, Twitter, Instagram
- LinkedIn, Reddit, Amazon, Wikipedia, GitHub

## 🛠️ Instalasi
1. Buka `chrome://extensions/`
2. Aktifkan **Developer Mode**
3. Klik **Load Unpacked**
4. Pilih folder extension

## 🎮 Kontrol
| Tombol | Fungsi |
|--------|--------|
| ▶️ Start | Mulai farming |
| ⏸️ Pause | Jeda sementara |
| ⏹️ Stop | Berhenti total |

## 🌙 Dark Mode
Toggle di Settings untuk mengaktifkan tema gelap.
